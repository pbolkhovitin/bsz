### Ключевые факты (2026-09-12)

- **Ядро:** CRS328 (bsz-sw-01, 106.5); аплинк RB5009 ether6 → bsz-sw-05 → CRS328 sfp-sfpplus4.
- **16 коммутаторов D-Link** имеют SNMP-доступ (MNG 101.x): bsz-sw-02/05/9/11-24.
- **bsz-sw-02 (DGS-3000-28XS)** — распределитель на CRS328 sfp-sfpplus1 (за ним bsz-sw-13/17/18 + камеры).
- **74 камеры** (Hikvision 51 + Dahua 23), ~34 EAP, ~19 Yealink, ~15 метеостанций.
- **Zabbix:** 57 хостов BSZ на прокси id=2; **NetBox:** 201 устройство.
