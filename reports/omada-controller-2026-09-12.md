## API (важно для автоматизации)
- **REST API v2 работает только с префиксом omadacId:**
  `/{omadacId}/api/v2/...` (например `/4431d2064b070040cd117d276f7ac8ad/api/v2/...`)
- Просто `/api/v2/...` — "Unsupported request path"
- Аутентификация: `POST /api/v2/login` → token (Csrf-Token заголовок)
- OpenAPI (client_id/secret) — **401** (параметры не приняты, возможно для облака)
- Данные надёжнее читать из **MongoDB** (порт 27217): коллекции `device`, `ssid`, `client`
